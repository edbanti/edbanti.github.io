# Self-hosted fonts

All three families are licensed under the SIL Open Font License 1.1 (see `OFL.txt`),
which permits redistribution and self-hosting.

| Family | Copyright | Source |
|---|---|---|
| Bricolage Grotesque | The Bricolage Project Authors | https://github.com/googlefonts/bricolage |
| Newsreader | Production Type | https://github.com/productiontype/Newsreader |
| JetBrains Mono | JetBrains s.r.o. | https://github.com/JetBrains/JetBrainsMono |

Only the `latin` and `latin-ext` subsets are included. Files are the same woff2
builds Google Fonts serves; `@font-face` rules live at the top of `/style.css`.
